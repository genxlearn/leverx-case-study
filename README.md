# LeverX case study

Duc Pham's portfolio case study for LeverX, a perpetual DEX on MegaETH. Live at https://leverx.ducpm.space.

This is a portfolio piece, not a LeverX product. It connects to no wallet and places no trades. Figures inside the screens are design sample data.

3D laptop: MacBook Pro M3 16-inch by jackbaeten (CC BY 4.0), rigged by William Laverty.
